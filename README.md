# Internet Speed Test Script

Консольный скрипт на Python для замера скорости скачивания данных из интернета.
Скрипт принимает URL, делает заданное количество последовательных запросов, дожидается полного ответа на каждый из них и выводит статистику.

## Единицы измерения

* **Объём данных:** Мегабайты (MB), где 1 MB = 1024 * 1024 байт.
* **Скорость скачивания:** Мегабиты в секунду (**Mbps**), где 1 Mbps = 1 000 000 бит в секунду.
  *(Именно в Mbps провайдеры обычно указывают скорость тарифного плана).*
* **Время:** Секунды (сек).

## Требования

* Python 3.8+
* Библиотека `requests`

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone <url_вашего_репозитория>
   cd internet-speed-test
   ```

2. Создайте виртуальное окружение:

   ```bash
   python3 -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

## Использование

Запустите скрипт, передав ему URL файла в качестве аргумента:

   ```bash
   python3 speedtest.py <URL>
   ```

## Пример запуска

(используется тестовый файл от Cloudflare размером ~25 MB):

```bash
   python3 speedtest.py "https://speed.cloudflare.com/__down?bytes=25000000"
   ```
